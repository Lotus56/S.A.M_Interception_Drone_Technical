# Development Instructions

S.A.M is a drone that autonomously tracks a target and intercepts it. New
work lives at the repository root. The navigation project it started from
is kept unchanged in `legacy/`; when working there, follow
[legacy/CLAUDE.md](legacy/CLAUDE.md) and run its commands from `legacy/`.

Commits are authored by the project's contributors. Do not add AI
co-author trailers or links to conversations in commit messages.

Every 3D-printed part goes in `hardware/parts/`: its print file in
`files/`, a photo of the print in `photos/`, and a row in that folder's
README.

Keep code comments and repository documentation in English.
